## [1.0.0] - 2026-09-18

### Added
- 🎉 Initial release of Songyot OS
- Base system built on Ubuntu 22.04 LTS
- XFCE desktop environment with custom theme
- Full Thai language support
  - Thai fonts (TH Sarabun, Loma, etc.)
  - Thai input method (IBus)
  - Thai locale (th_TH.UTF-8)
- Pre-installed essential software:
  - Firefox web browser
  - LibreOffice suite
  - GIMP image editor
  - VLC media player
  - Git version control
  - Vim text editor
- Custom branding:
  - Songyot OS logo
  - Custom wallpapers
  - Custom color scheme
- Build system:
  - Automated ISO builder script
  - Desktop customization script
  - Package installation script
  - System info display script
- Documentation:
  - Installation guide (Thai/English)
  - Build instructions
  - FAQ
  - Contributing guidelines
  - Quick start guide
- Bootloader configuration with GRUB2
- Live USB support with Casper
- EFI and Legacy BIOS support

### System Specifications
- **Base**: Ubuntu 22.04 LTS (Jammy Jellyfish)
- **Desktop**: XFCE 4.16
- **Display Manager**: LightDM
- **Kernel**: Linux 5.15+ (Generic)
- **Architecture**: AMD64 (x86_64)
- **Minimum Requirements**:
  - CPU: 2 GHz dual-core
  - RAM: 4 GB
  - Storage: 25 GB
  - Display: 1024×768

## Release Notes

### Version 1.0.0 - "Stable Release"

This is the first stable release of Songyot OS, designed specifically for Thai users who want a reliable, easy-to-use Linux distribution.

**What's Included:**
- Fully localized Thai interface
- Pre-configured Thai input methods
- Curated selection of essential applications
- Optimized for performance and stability
- Beautiful custom theme and wallpapers

**Installation:**
1. Download ISO from [Releases](https://github.com/songyot-os/songyot-os/releases)
2. Create bootable USB
3. Boot and install
4. Enjoy! 🎉

**Testing:**
This release has been tested on:
- VirtualBox 7.0
- QEMU/KVM
- Physical hardware (various configurations)

**Feedback:**
Please report any issues on [GitHub Issues](https://github.com/songyot-os/songyot-os/issues)

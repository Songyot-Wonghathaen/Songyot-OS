# Songyot OS - Branding Assets

This directory contains all branding materials for Songyot OS.

## Directory Structure

```
branding/
├── logos/          # Logo files in various formats
├── wallpapers/     # Desktop wallpapers
└── themes/         # Desktop themes and color schemes
```

## Logos

### Requirements
- **Formats**: SVG (vector), PNG (raster)
- **Sizes**: 
  - 512x512 (app icon)
  - 256x256 (system icon)
  - 128x128 (panel icon)
  - 64x64 (small icon)
  - 32x32 (favicon)
- **Color modes**: Full color, monochrome, white on transparent

### Naming Convention
- `songyot-logo.svg` - Main vector logo
- `songyot-logo-512.png` - App icon
- `songyot-logo-mono.svg` - Monochrome version
- `songyot-icon-*.png` - Various sizes

## Wallpapers

### Requirements
- **Format**: JPG (lossy), PNG (lossless with transparency)
- **Resolutions**: 
  - 3840x2160 (4K)
  - 2560x1440 (QHD)
  - 1920x1080 (Full HD)
  - 1366x768 (Laptop)
- **Aspect ratios**: 16:9, 16:10, 4:3

### Naming Convention
- `songyot-default-*.jpg` - Default wallpaper
- `songyot-abstract-*.jpg` - Abstract designs
- `songyot-nature-*.jpg` - Nature themes

### Design Guidelines
- **Color scheme**: Navy (#0F172A), Cyan (#22D3EE), Orange (#F97316)
- **Style**: Modern, clean, professional
- **Theme**: Thai cultural elements (subtle)

## Themes

### Desktop Theme Components
- **GTK theme**: Window decorations, widgets
- **Icon theme**: System and application icons
- **Cursor theme**: Mouse pointer
- **Color scheme**: System-wide colors

### Files
- `Songyot-Dark/` - Dark theme (default)
- `Songyot-Light/` - Light theme
- `Songyot-Icons/` - Icon set

## Design Guidelines

### Color Palette

**Primary Colors:**
- Deep Navy: `#0F172A` (backgrounds)
- Slate: `#1E293B` (panels)
- Cyan: `#22D3EE` (accents, links)
- Orange: `#F97316` (highlights, CTAs)

**Text Colors:**
- Primary: `#F8FAFC` (light text)
- Secondary: `#94A3B8` (muted text)
- Dark: `#0F172A` (on light backgrounds)

**Status Colors:**
- Success: `#10B981` (green)
- Warning: `#F59E0B` (amber)
- Error: `#EF4444` (red)
- Info: `#3B82F6` (blue)

### Typography
- **System Font**: Inter, Sora, IBM Plex Sans
- **Monospace**: JetBrains Mono, Fira Code
- **Thai Font**: Sarabun, Prompt, Kanit

### Logo Usage

**DO:**
- ✅ Use official logo files
- ✅ Maintain aspect ratio
- ✅ Provide clear space around logo
- ✅ Use on appropriate backgrounds

**DON'T:**
- ❌ Stretch or distort logo
- ❌ Change colors arbitrarily
- ❌ Add effects (shadows, gradients)
- ❌ Place on busy backgrounds

## Contributing

Want to contribute artwork?

1. Follow design guidelines above
2. Create high-quality assets
3. Test on actual system
4. Submit via Pull Request

### Asset Checklist
- [ ] High resolution (vector if possible)
- [ ] Multiple sizes provided
- [ ] Follows color scheme
- [ ] Tested on dark/light themes
- [ ] Properly licensed
